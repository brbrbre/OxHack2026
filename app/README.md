# app/ - la app (Carlos)

React con Vite. La persona elige activo, monto, plazo y perfil, y ve la decisión, la gráfica y las razones.

Solo habla con el API (`api/README.md`). No importa nada de Python.

```bash
cd app
npm install
npm run dev        # http://localhost:5173, con /api redirigido a http://localhost:8000
```

En pantalla siempre: el aviso y las fuentes de datos que manda el API en `aviso`.
